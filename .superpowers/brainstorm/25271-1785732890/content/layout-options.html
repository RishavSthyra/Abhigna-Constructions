Responsive gallery spacing

The two options below show how the gallery can behave as the viewport narrows.

A — Keep all cards, scale aggressively

All cards remain mounted, so spacing becomes too tight and cards can collide.

B — Responsive visible-card count

Fewer cards are rendered on small screens; a fixed minimum gap is preserved.

Recommendation

Use option B: select 3 cards on mobile, 5 on tablet, and all cards on desktop. Keep the existing curved motion and use the available width to size the selected cards with a consistent gap.
